# 侧边工作台 · SideDesk

Chrome MV3 扩展：**一块侧边面板 = 左侧收藏快捷栏 + 右侧网页浏览区**，每条链接可独立配置打开方式，支持浅色/深色主题。

## 目录结构

```
chrome-sidepanel-extension/
├─ manifest.json      # MV3 清单（sidePanel / storage / tabs / activeTab）
├─ background.js      # 后台：工具栏点击开面板 + 快捷键
├─ sidepanel.html     # 面板结构
├─ sidepanel.css      # 主题变量 + 全部样式
├─ sidepanel.js       # 全部逻辑
└─ icons/             # 16/32/48/128 图标
```

## 布局

- **左侧（主区域）**：网页浏览区 —— 顶部返回/前进/刷新/地址栏，下面是内嵌网页
- **右侧（窄栏，默认 56px）**：竖向网站图标栏 —— 顶部 ⊕ 抓取 / ✎ 添加，中间是图标列表，底部是主题 / 管理

图标栏可拖动中间的竖条调整宽度（宽度会记住）。图标悬停显示名称提示，右上角浮出 ✎ 编辑 / ✕ 删除，可直接拖动排序。设为「新标签打开」的图标右下角带 ↗ 角标。

配色为纯黑白（浅色模式白底黑字，深色模式黑底白字）。

## 安装（开发者模式）

1. Chrome 地址栏打开 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本文件夹
4. 出现「侧边工作台 · SideDesk」卡片即成功

> 需要 Chrome 114 及以上（`chrome.sidePanel` API 要求）。

## 使用

| 操作 | 效果 |
|---|---|
| 点工具栏紫色图标 | 打开侧边面板 |
| `Ctrl + Shift + E` | 打开面板（可在 `chrome://extensions/shortcuts` 改键） |
| 拖动中间竖条 | 调整左右宽度（记忆保存） |
| 左栏顶部「抓取当前页」 | 一键采集当前标签页标题/网址/图标，自动归类 |
| 左栏「手动添加」 | 填名称、网址、分组、打开方式 |
| 条目 ✎ / ✕ | 编辑 / 删除 |
| 条目 ⋮⋮ 拖动 | 排序 |
| 右上角 ◐ | 主题循环：跟随系统 → 浅色 → 深色 |

## 单链接打开方式（四种）

每个链接可独立选择（悬停图标 → ✎ 编辑）：

| 模式 | 说明 | 适用 |
|---|---|---|
| **在左侧页面内打开** | iframe 内嵌，与侧边栏一体 | 允许被嵌入的网站（文档、翻译、论坛等），延迟最低 |
| **镜像到侧边栏内（可交互）** | 把真实浏览器窗口的渲染画面抓下来显示在侧边栏，鼠标键盘实时转发回网页 | **ChatGPT、Claude、Gemini、Notion、GitHub、Gmail** 等禁嵌站点 —— 效果与真实浏览器一致，能输入、能点击、能滚动 |
| **在独立小窗打开** | 弹出真正的 Chrome 独立窗口 | 想要一个能自由拖动的窗口时 |
| **直接新标签页打开** | 单击即开新标签 | Gmail、谷歌日历等 |

图标右下角角标：**▣** = 镜像模式，**❐** = 小窗模式，**↗** = 新标签模式，无角标 = 面板内模式。

还可单独设置「单击即打开」或「双击才打开」，避免误触。

## 镜像模式是怎么做到的（技术说明）

iframe 内嵌受服务端 `X-Frame-Options` / CSP `frame-ancestors` 限制，**无法绕过**。
镜像模式换了一条完全不同的路：

1. 插件创建一个**真实的 Chrome 浏览器窗口**，在里面正常打开目标网址（由浏览器本体渲染，XFO 管不着）
2. 通过 Chrome DevTools Protocol 的 `Page.startScreencast`，把该窗口的渲染帧持续抓下来
3. 帧经长连接端口（`chrome.runtime.connect`）推给侧边栏，绘制到 `<img>` 上
4. 侧边栏上的鼠标移动/点击/滚轮/键盘，经 `Input.dispatchMouseEvent` / `Input.dispatchKeyEvent` **转发回真实页面**
5. 用 `Emulation.setDeviceMetricsOverride` 把页面视口尺寸改成侧边栏的实际尺寸，保证排版正确

代价：需要 `debugger` 权限（Chrome 会显示「正在调试此浏览器」提示条，属正常现象）。承载窗口会被贴在屏幕最右侧边缘（大部分在视野外），保证 Chrome 持续渲染出帧。

### 关于被拒绝嵌入

⚠️ 服务器可下发 `X-Frame-Options: DENY/SAMEORIGIN` 或 CSP `frame-ancestors 'none'`，
这是浏览器**收到响应头那一刻**的硬性拦截，**任何 Chrome 扩展都绕不过**（ChatGPT、Claude、Gemini、Notion、GitHub、Gmail、谷歌日历都属于这类）。扩展**不尝试绕过**，而是换用镜像/小窗/新标签来承载。

插件的处理方式：
1. 内置禁嵌站点名单 + 响应头探测，**点击前**就判定，避免出现 Chrome 那个丑陋的「拒绝了我们的连接请求」错误页
2. 判定为禁嵌时**自动切换到镜像模式**，画面直接进侧边栏且完全可交互
3. 该链接的打开方式会被记住，下次点击直接走镜像

## 权限说明（最小权限）

| 权限 | 用途 |
|---|---|
| `sidePanel` | 显示侧边面板 |
| `storage` | 本地持久化收藏、主题、宽度 |
| `tabs` | 读取当前标签页标题/网址/favicon（抓取功能） |
| `activeTab` | 仅在用户点击扩展时临时访问当前页 |
| `debugger` | 镜像模式必需的 CDP 协议（抓帧 + 输入转发）。Chrome 会显示「正在调试此浏览器」提示条，属正常 |

无云同步、无跨设备同步、无后台常驻。

## 数据

全部存于 `chrome.storage.local`，重启浏览器、关掉面板都不丢。「管理」面板支持导出 / 导入 JSON 备份。

## 已知限制

- 跨域 iframe 无法读取内部跳转记录，因此面板的「返回/前进」是**面板自己维护的地址栈**，只对「通过面板打开过的地址」有效
- 部分站点登录态与新标签页共享（同一浏览器 profile），一般可直接用
- Gmail、谷歌日历等无法内嵌，必须走「新标签页」模式
