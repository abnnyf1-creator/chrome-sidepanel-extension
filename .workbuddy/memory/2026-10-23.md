## 修正：chrome.permissions.request 不支持 microphone
- 实测报错：`请求权限失败：'microphone' is not a recognizable permission.`
- 原因：Chrome 的 `chrome.permissions.request` 白名单不含 `microphone`（也含 camera 等媒体设备权限），只能在 manifest 声明，授权由浏览器在首次 `getUserMedia` 时弹框完成。
- 修正方案：
  - 删除 `chrome.permissions.request/contains` 相关逻辑。
  - `refreshMicState()` 改用标准 Web 权限 API `navigator.permissions.query({name:'microphone'})` 仅做状态展示（granted 显示绿点）。
  - 点击麦克风按钮直接 `openMicModal()` → `getUserMedia({audio:true})`，由 Chrome 原生弹授权框；成功/失败都 `refreshMicState()` 同步绿点。
- 重新加载扩展后生效。
